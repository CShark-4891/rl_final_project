# Training Results

This folder contains the results of the training runs for the CQL algorithm across various D4RL/Minari datasets. Each subdirectory corresponds to a specific dataset and contains the trained model and evaluation metrics. Training logs can be found inside the pipeline/logs/ directory.

## Environments

The following environments were used for training and evaluation:
-   `hopper`
-   `halfcheetah`
-   `walker2d`
