# Training Results

This folder contains the results of the training runs for the CQL algorithm across various D4RL/Minari datasets. Each subdirectory corresponds to a specific dataset and contains the trained model and evaluation metrics. Training logs can be found inside the pipeline/d3rlpy_logs/ directory.

## Environments

The following environments were used for training and evaluation:
-   `hopper`
-   `halfcheetah`
-   `walker2d`

## D3rlpy paper results and self-trained models

In the folder d3rlpy_paper you can find the results of the CQL and other algorithms as reported in the D3rlpy paper. The folder self_trained contains the results of our own trained CQL models using the same algorithm and hyperparameters as in the paper.
